### 3. ikow/php2shell-poc（+914，总 938，Python）

**场景分析员**：今天真正的「主角仓库」。作者 Qi Deng 发布的 php2shell 研究仓：CVE-2026-109618（OOM 导致 Zend 引擎状态损坏→RCE）与 CVE-2026-109619（FPM worker 跨请求残留状态→UAF→RCE），五条独立攻击链，PHP 5.4（2012 年）到 8.5.11 全中招，未授权即可触发，部分链不需要应用本身有漏洞。时间线戏剧化：10-20 HN 泄露帖 + Kevin Beaumont 预警 → 10-21 PHP 紧急发布修复版（8.2.35/8.3.36/8.4.27/8.5.12），PHP 5.x/7.x/8.0/8.1 已 EOL **永远不会有补丁**。

**质疑者**：创建当天 +914 纯事件驱动；sploitus、watchTowr、Sansec、abstract.security 等多家安全机构均有独立分析佐证，非刷量。需要提醒的是此类仓库会吸引攻击者而非仅防御者，star 数里混着黑产。可信度：**中高**（研究真实，star 构成复杂）。

**主编**：今天最值得行动——不是关注而是**立刻升级 PHP 到 8.2.35+**；暂不能升级的先关 `session.upload_progress`、在代理层限制 multipart 请求体。EOL 版本的存量网站是下一波勒索事件的火药桶。

## 四、趋势洞察

1. **php2shell 是 2026 年迄今最严重的 Web 基础设施事件。** 14 年代码历史、78% 网站、未授权 RCE、补丁前泄露、在野利用、EOL 版本永久无补丁——每个要素都是顶格。对开发者的直接行动项：PHP 升到 8.2.35/8.3.36/8.4.27/8.5.12；不能升的先关 `session.upload_progress` 并在边缘限制 multipart 体积。GitHub 上 PoC/检测工具单日扎堆上榜（ikow、NCSC-NL、openai 名下待证实的 checker），安全事件的「GitHub 响应链」已成标准流程。

2. **「电视去广告」品类进入双格局收敛期。** cleanyourtv 逼近 2 万星锁定品类冠军，aerial-tv 以「国产电视开箱即用」的差异化路线冲到第二梯队头部——模仿者中已有掉队迹象，预计下周品类固化。

3. **推理加速成为继模型之后的第二个「军备竞赛公开化」领域。** DeepInfer 开源（DSpark 推测解码）+ EAGLE-4 发布 + NVIDIA 开仓 flare-local-inference 三天内连发，推理层的竞争从论文走向生产代码，受益最大的是自部署模型的企业。
